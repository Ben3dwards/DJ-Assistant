About DJ Assistant

DJ Assistant is an AI-powered tool designed to help DJs build harmonically compatible setlists, search new tracks or recomend track from a local drum and bass track database.

It uses an AI language model to interpret your requests and call the appropriate tools. Occasionally the model will ignore its tools and respond from memory instead. This means it may confidently tell you a setlist has been exported to Spotify when it has not actually done so.

If this happens, simply tell it off. Responses like "use your tools" or "actually export it" are enough to get it back on track. The model responds well to being corrected.

How it works

When you ask for a setlist, DJ Assistant starts from the track you give it and repeatedly finds the next best track using a scoring algorithm. Each candidate track is scored against the current track across four dimensions:

  • Harmonic compatibility (Camelot wheel)
  • Energy similarity
  • Danceability similarity
  • Tempo / BPM similarity

The tool also keeps recommendations within a ±4 year window of the current track to maintain era coherence: liquid funk from 2006 won't be mixed with neurofunk from 2018.

Harmonic mixing and the Camelot Wheel

Harmonic mixing is the practice of only mixing tracks that share compatible musical keys. The Camelot Wheel makes this visual - each position on the wheel represents a key, and adjacent positions mix well together.
